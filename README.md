# Backrooms 日本語字幕サイト

字幕制作リポジトリから、サイトの実行に必要なファイルだけを切り出したものです。独立したGit履歴で管理します。元のサイトのスナップショットは `e770414` です。

## ローカル確認

Node.js 20以降で、このフォルダから `npm run dev` を実行し、`http://127.0.0.1:4180/` を開きます。字幕はHTTP経由で読み込むため、`file://` では動作しません。

## 公開前の確認

- 22作品の翻訳字幕について、Web掲載の許諾は未確認である。公開判断と停止対応をサイト所有者が管理する。
- フッターの非公式表記、公式チャンネルへのリンク、意見フォームと連絡先を最終確認する。
- プロジェクトサイトのサブパスで、動画、字幕、設定、フォーム、連絡先を確認する。
- 映像内字幕はサイト所有者の判断で有効。YouTubeの埋め込み要件はプレーヤー前面のオーバーレイを禁止している。必要に応じて `config.js` で無効化できる。
- 作品を停止するときは `episodes.json` の設定に加え、公開している該当SRTファイルも削除する。

SRTはブラウザに配信される静的ファイルです。サイトが公開されれば、閲覧者はSRTを取得できます。
