# Backrooms 日本語字幕サイト（公開候補）

字幕制作リポジトリから、サイトの実行に必要なファイルだけを切り出したローカルの候補です。独立したGit履歴で管理します。元のサイトのスナップショットは `e770414` です。現時点ではGitHubのリモートやPagesへ送信していません。

## ローカル確認

Node.js 20以降で、このフォルダから `npm run dev` を実行し、`http://127.0.0.1:4180/` を開きます。字幕はHTTP経由で読み込むため、`file://` では動作しません。

## 公開前の確認

- 22作品の翻訳字幕をWeb掲載する許諾・条件を確認する。
- フッターの「ローカル開発版・一般公開していません」という案内を、公開時の事実に合わせて修正する。
- プロジェクトサイトのサブパスで、動画、字幕、設定、フォーム、連絡先を確認する。
- 埋め込みプレーヤーの前面に字幕を重ねない。公開候補では `config.js` で映像内字幕を無効にしている。
- 作品を停止するときは `episodes.json` の設定に加え、公開している該当SRTファイルも削除する。

SRTはブラウザに配信される静的ファイルです。サイトが公開されれば、閲覧者はSRTを取得できます。
